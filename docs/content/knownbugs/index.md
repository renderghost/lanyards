# 🐞Known Bugs

## WSOD
Sometimes, if you're signed in, after we update the app, you might see a white screen when you try to open the app. Clearing site data will help.

### Chrome — Desktop
1. Click the padlock icon beside the address bar.
2. Select **Site settings**.
3. Under **Usage**, click **Clear data**.
4. Click **Clear** to confirm.

### Chrome — iOS
1. Tap the **•••** menu in the bottom-right corner.
2. Go to **Settings** → **Privacy**.
3. Tap **Clear Browsing Data**.
4. Select **Cookies, Site Data** and **Cached Images and Files**.
5. Tap **Clear Browsing Data**.

### Chrome — Android
1. Tap the **⋮** menu in the top-right corner.
2. Go to **Settings** → **Privacy and Security**.
3. Tap **Clear browsing data**.
4. Choose **Cookies and site data** and **Cached images and files**.
5. Tap **Clear data**.

### Firefox — Desktop
1. Click the padlock icon beside the address bar.
2. Select **Clear cookies and site data…**
3. Click **Remove** to confirm.

### Firefox — iOS
1. Tap the **≡** (three lines) menu.
2. Go to **Settings** → **Data Management**.
3. Enable **Cache** and **Cookies**.
4. Tap **Clear Private Data**.

### Firefox — Android
1. Tap the **⋮** menu.
2. Go to **Settings** → **Delete browsing data**.
3. Select **Cookies** and **Cached images and files**.
4. Tap **Delete browsing data**.

### Safari — macOS (Desktop)
1. Go to **Safari** → **Settings** in the menu bar.
2. Open the **Privacy** tab.
3. Click **Manage Website Data…**
4. Select a site and click **Remove**, or click **Remove All**.

### Safari — iOS
1. Open **Settings**.
2. Scroll to **Safari**.
3. Tap **Advanced** → **Website Data**.
4. Tap **Remove All Website Data**, or remove specific sites.
